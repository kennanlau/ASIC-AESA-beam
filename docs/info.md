## How it works

The beam steering engine turns a steering direction into the phase setting of every element of a 4x4
phased array with half-wavelength spacing. Phases come out as 7-bit words in 2.8125 degree steps, the
resolution of the ADAR1000 beamformer, ready to be converted to I/Q codes and loaded by the AESA Digital
Brain v2.1 SPI engine.

Element n = iy*4 + ix. The engine holds two signed 12-bit phase increments, Dx and Dy, in 1/16 of a phase
step, and computes

    phase(n) = floor((8 - (ix*Dx + iy*Dy)) / 16) mod 128

which is the steering phase -pi*(ix*sin(theta_x) + iy*sin(theta_y)) rounded to the nearest step.

Dx and Dy can be written directly, or set from an angle: in angle mode the input byte is a signed angle in
degrees (clamped to +/-90) and a 91-entry sine table gives D = round(1024*sin(angle)). The table is
generated by tools/gen_sin_lut.py.

### Writing (value on uio, select on ui[3:1], rising edge on ui[0])

| sel | Action |
|---|---|
| 0 | Dx[7:0] |
| 1 | Dx[11:8] (uio[3:0]) |
| 2 | Dy[7:0] |
| 3 | Dy[11:8] (uio[3:0]) |
| 4 | Angle in x: uio = signed degrees, sets Dx |
| 5 | Angle in y: uio = signed degrees, sets Dy |
| 6 | Clear Dx and Dy |

uo[7] toggles on every accepted write. Holding ui[0] high writes only once.

### Reading

Put the element index on ui[7:4]; its phase appears on uo[6:0] three clock cycles later.

## How to test

1. Clock at 50 MHz, reset.
2. Write sel 4 with uio = 30 (steer 30 degrees in x).
3. Read elements 0..3: expect 0, 96, 64, 32 (0, -90, -180, -270 degrees).

The cocotb tests check every angle from -90 to +90 degrees bit-exactly against a Python model, check a
2-D grid of angles and 40 random direct settings, compare against the ideal phase (worst error 0.57 steps,
1.6 degrees), and lock the full angle table to a SHA-256 golden hash. A missing golden fails the test.

## External hardware

None required. Pairs with AESA Digital Brain v2.1 (tt_um_kennanlau_aesa_brain_v2), which sends the
resulting settings to ADAR1000 beamformers over SPI.
